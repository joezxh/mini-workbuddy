Mock 模式

默认开启：REST 返回样例转写 / 合成 WAV（正弦提示音），WS 由后端模拟 Realtime 事件序列（session.created → speech_started → 转录 → audio.delta → response.done）， 前后端联调不依赖任何真实模型服务。右上角开关即对应 VOICE_DEMO_MOCK（前端下拉可临时切换，真实开关以后端配置为准）。

切换真实服务（2026-11-10 已实测）

本地 127.0.0.1:8765 同主机提供 OpenAI 兼容 REST 与 /v1/realtime，默认配置即真实全功能：
ASR：POST /v1/audio/transcriptions（multipart file+language）→ {"text","language"}（language 为语言名，如 "Chinese"）；
TTS：POST /v1/audio/speech（JSON input/voice/response_format，仅 wav，无 speed 字段）→ WAV 字节；voice=Aiden 实测有效；
WS 容器内 E2E：docker exec speech-to-speech-thirdparty-pipeline-1 python3 /tmp/e2e_realtime_test.py --url ws://127.0.0.1:8765/v1/realtime --audio /tmp/prompt.wav --out-dir /tmp/e2e --timeout 90；
切换：置 VOICE_DEMO_MOCK=false 即可（默认 BASE_URL / WS 已指向本机，无需改）。

主题

浅色 / 深色双主题可切换（顶栏按钮），与控制台一致：<html data-theme="light|dark"> + localStorage['app-theme']，默认浅色。 实现时复用 useAppStore().toggleTheme() 与 styles/tokens.css 双皮肤变量，不另建主题机制；原型 CSS 变量即工程 token 的别名映射。

已知限制与风险

  • s2s 为单实例串行（pool size 1）：多用户并发需排队或扩容（后端桥接层加并发闸门并给出友好 503）。
  • 会话上下文由 s2s 服务端持有，无持久化：刷新即新会话；如需落库沿用 duplex 既有会话存储方案（P1）。
  • 浏览器兼容：Chrome / Edge ≥ 110（AudioWorklet）；Electron 下需核对麦克风权限；无 WebRTC fallback（预留）。
  • 音色固定为服务端 speaker 集；speed / response_format 服务端暂未生效（占位透传）。
