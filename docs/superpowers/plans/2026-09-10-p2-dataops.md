# P2 · 业务数据集成与处理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移植 ontomind DataOps 能力到 MinWorkBuddy：数据源管理、元数据扫描、列画像、元数据标准绑定、SQL 只读执行与写操作审批，并产出供知识库（P1）与本体（P4）消费的业务语义。

**Architecture:** 服务层不感知数据库方言；方言差异收敛到 `DialectAdapter` 实现（首批 MySQL / Doris / PostgreSQL）。SQL 执行分读写两条路径：只读走解析白名单 + 只读事务 + 限制层；写操作走「Dry-run 影响预估 → 申请 → 管理员批准 → 一次性令牌执行」。AgentScope Tool 侧权限复用原生 `PermissionEngine`，与 REST 侧共用同一份白名单定义。

**Tech Stack:** Python 3.11 / FastAPI / SQLAlchemy 2.0（`identifier_preparer.quote()` 处理标识符）/ pymysql / sqlglot / cryptography(Fernet，随 `python-jose[cryptography]` 已有) / AgentScope 2.0.7 / pytest

**Spec:** `docs/superpowers/specs/2026-09-10-dataops-integration-design.md`
**依赖：** P1（结构化数据入湖目标）

# backend/app/ai/dataops/crypto.py
from cryptography.fernet import Fernet
from app.config import settings

def _fernet() -> Fernet:
    key = (settings.DATAOPS_ENCRYPTION_KEY or "").strip()
    if not key:
        raise RuntimeError(
            "DATAOPS_ENCRYPTION_KEY 未配置，拒绝降级为明文存储"
        )
    return Fernet(key.encode())

def encrypt_secret(raw: str) -> str:
    return _fernet().encrypt(raw.encode()).decode()

def decrypt_secret(token: str) -> str:
    return _fernet().decrypt(token.encode()).decode()
```

在 `config.py` 增加 `DATAOPS_ENCRYPTION_KEY: str = ""`。
**不得**复用 `SECRET_KEY`（默认值为硬编码弱密钥，且密钥混用）。

# backend/app/ai/dataops/dialect_base.py
@dataclass
class ColumnMeta:
    name: str; ordinal: int; data_type: str; nullable: bool; comment: str | None
    column_key: str | None

class DialectAdapter(Protocol):
    name: str
    def list_databases(self, conn) -> list[str]: ...
    def list_tables(self, conn, database: str) -> list[TableMeta]: ...
    def list_columns(self, conn, database: str, tables: list[str]) -> dict[str, list[ColumnMeta]]: ...
    def profile_column(self, conn, database, table, column, sample_rows) -> dict: ...
    def overlap_ratio(self, conn, database, left, right) -> float: ...
    def dry_run(self, conn, sql: str) -> dict: ...
```

**标识符一律用 `dialect.identifier_preparer.quote()`，禁止手写反引号 `_ident()`。**
PG 注释须用 `col_description()` / `obj_description()` 从 `pg_catalog` 取。

## 验收标准

| 项 | 标准 |
|---|---|
| 方言 | 三个适配器对同一 fixture 返回结构一致 |
| 幂等 | 同一库连扫两次，meta_table/meta_column 不增行 |
| SQL 安全 | Task 8 全部 10 条用例通过；令牌重放与篡改 SQL 被拒 |
| 租户 | 租户 A 访问不到租户 B 的数据源与元数据 |
| 凭据 | 密码加密落库，API 不返回明文，未配 key 时启动报错 |
| 置信度 | 0.90/0.70/0.50 分别落到 accepted/suggested/丢弃 |
| 关系推断 | veto 生效；无 LLM 时权重归一化正确 |

## 风险与退路

| 风险 | 退路 |
|---|---|
| sqlglot 对 Doris 方言支持有限 | 先用 MySQL 方言解析验证；不可靠则退化为只读事务兜底 + 严格白名单正则（安全性下降，需记录） |
| 大库扫描超时 | 默认关闭 `with_profile`；容量上限保护 |
| 飞书/钉钉类 token 刷新（本计划不涉及） | — |
